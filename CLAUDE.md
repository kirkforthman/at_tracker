# at_tracker

Live map of airline traffic over the continental US with a focus panel and an LLM chat pane.
Portfolio project: deterministic ingest + relational/graph data, agentic chat over curated MCP tools.

## Layout

    dashboard/   Flask + D3 UI, reads Postgres (read-only)
    ingest/      Python worker: OpenSky, FAA NAS Status, METAR, enrichment
    scripts/     dev setup and smoke tests
    docs/adr/    decisions;  docs/plans/  one plan per milestone;  docs/WORKLOG.md

## Rules

- **Airline traffic only.** Every OpenSky response goes through `at_ingest.filter.filter_states()`
  before anything is written to a DB, a log, a cache or a test fixture. Never store, print or commit
  dropped state vectors; only counts and unmatched callsign prefixes. See docs/adr/0002.
- **No real aircraft data in git.** OpenSky/adsbdb fixtures are synthetic (`_synthetic: true`,
  generated by `ingest/tests/fixtures/generate_synthetic.py`). Real responses go to the gitignored
  `ingest/recordings/` only.
- **Only `ingest` calls external APIs.** The UI and chat read local databases.
- Schema changes are new files in `ingest/migrations/NNN_*.sql` (applied at worker start); never edit
  an applied migration.
- **Postgres is the source of truth; Neo4j is a rebuildable projection.**
- **The LLM never writes to a database**, and the map/focus box never depend on it.
- **Portable:** no host paths, no OS-specific code; config through `.env` (see `.env.example`).
  Only the LLM location varies per host (`LLM_BASE_URL`). See docs/adr/0001.
- OpenSky budget: 4,000 credits/day, 4 credits per CONUS call, poll every 90 s. Don't add calls
  without checking the budget.
- Never commit `.env` or real credentials.
- **Pin known-good versions** (docs/adr/0003): `==` Python deps in `requirements.txt`, action SHAs,
  image `tag@sha256:digest`, model revision + SHA-256. Bumps come through Dependabot PRs.
- `main` is protected: work on a branch and open a PR; CI must pass before merging.

## Commands

    docker compose up -d --build                  # postgres + ingest (live OpenSky) + dashboard
    INGEST_SOURCE=replay docker compose up -d     # synthetic data instead of OpenSky
    docker compose --profile gpu-nvidia up -d     # ...plus the local LLM on :8081
    docker compose logs -f ingest                 # poll log

    cd ingest && python3 -m venv .venv && .venv/bin/pip install -r requirements-dev.txt && .venv/bin/pip install --no-deps -e .
    .venv/bin/pytest -q && .venv/bin/ruff check . ../dashboard ../scripts   # DB tests need Postgres (compose)
    .venv/bin/python -m at_ingest.probe all          # real responses -> ingest/recordings/ (gitignored)
    .venv/bin/python tests/fixtures/generate_synthetic.py   # regenerate synthetic fixtures
    python3 scripts/llm_smoke_test.py                # needs a running model at LLM_BASE_URL
    python3 scripts/compose_smoke.py                 # end-to-end check of a running replay stack
